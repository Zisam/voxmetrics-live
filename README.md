# voxmetrics live

Live-график высоты голоса в браузере — как вокальный тюнер: ноты на шкале, кривая F0 в реальном времени и панель метрик голоса (вибрато, тон, спектр).
Интерфейс, подсказки тренера и руководство переведены на русский, английский и японский (селектор RU/EN/JA в тулбаре, выбор запоминается).
В центре экрана всплывают короткие игровые подсказки по технике — «Вибрато быстрее!», «Качается громкость!», «Отлично!» — цвет по важности, максимум одна за раз.
Кнопка «?» в тулбаре открывает руководство для новичков: что означает каждая подсказка и какие упражнения делать. Вибрато разбирается по ритмической модели (как барабанная дробь): встроенный метроном (клик на каждый 4-й качок волны) и синусоида-эталон следуют ползунку BPM; лестница 60→83 BPM, критерии перехода по метрикам (стабильность темпа ≤ 10 %, регулярность ≥ 60 %).
Референсы вибрато — анализ исполнителей (Ruki / the GazettE «Dogma»: 5.8 Hz 190 ¢ и 5.3 Hz 132 ¢; 茅原実里: 5.64 Hz 146 ¢; M. Shadows / Avenged Sevenfold «The Stage»: 5.79/169, 5.64/125, 5.29/67 ¢). Кнопка «Эталон» рисует на графике жёлтый коридор 150 ¢ вокруг ноты и зелёную эталонную синусоиду 5.5 Hz, заполняющую коридор от края до края.
Кнопка «Скачать метрики» в подвале выгружает метрики сессии в TSV (снапшот каждые 2 с, 23 колонки, включая вибрато с период-стабильностью, тремоло, jitter/shimmer/CPP/форманты) — открывается в Excel или Google Sheets для отслеживания прогресса между занятиями.
Все вычисления выполняются локально — аудио не отправляется на сервер.

Демо: https://zisam.github.io/voxmetrics-live/

Алгоритмы портированы из приватного Python-проекта voxmetrics: F0, вибрато, LTAS, H1-H2, форманты.
Метрики обновляются каждые 2 с по скользящему окну 6 с: частота/размах/регулярность вибрато, тремоло (амплитудная модуляция 3–9 Гц — «ложное вибрато»), медиана F0 с нотой, форманты F1–F3, певческая форманта (пик 2.4–3.2 кГц и его выраженность), jitter, shimmer, CPP, H1−H2, спектральный центроид, S/F-баланс и LTAS-спектр.
Эталонные диапазоны показаны прямо в панели (легенда: норма / допустимо / вне нормы): вибрато 4.5–7.5 Гц с размахом 40–250 центов, регулярность ≥ 60 %, надёжность ≥ 4 с ровного тона, певческая форманта ≥ 6 дБ над фоном, jitter ≤ 0.15 %, shimmer ≤ 0.05 дБ (покадровые пороги, откалиброваны для этого измерения — не сравнивайте с экспортом Praat), CPP ≥ 4 дБ (ориентир, своя шкала: чистый шум ~0.4 дБ, здоровый голос 4–7 дБ); форманты и тон — ориентировочные/индивидуальные, зависят от гласного и типа голоса. Jitter/shimmer/CPP сильно зависят от микрофона и расстояния — главное их значение это тренд между подходами.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:5173/voxmetrics-live/ и разрешите доступ к микрофону.

## Сборка

```bash
npm run build
```

## Ограничения live-режима

- Скользящее окно **5 с**: история движется влево, текущий сэмпл закреплён справа (ось X 0…5 с).
- Селектор канала в тулбаре: C (микс L+R, по умолчанию), L, R — для стерео-интерфейсов; моно-микрофон работает при любом положении. Выбранный канал сохраняется между сессиями.
- Нойз-гейт в тулбаре: порог RMS (дБFS) по умолчанию −50 дБ, регулируется ползунком (−90 дБ практически выключен). Гистерезис 4 дБ и сглаженные атака/релиз — без щелчков и дребезга.
- Узкополосный режектор 50 Гц убирает фон сети до анализа (не влияет на голос от 45 Гц и струны).
- Отклонение в центах (HUD) центрируется по медиане последних ~400 voiced-фреймов F0 (~2 с непрерывного звука при hop 5 ms).
- Realtime F0 и тяжёлый анализ метрик разделены по воркерам: анализ окна 6 с занимает <1 с и не тормозит график.
- «Надёжное» вибрато требует ≥4 с непрерывного озвученного звука в окне анализа.
- Для точного офлайн-анализа предназначен приватный Python-проект voxmetrics.
