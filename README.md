# voxmetrics live

Live-график высоты голоса в браузере — как вокальный тюнер: ноты на шкале, кривая F0 в реальном времени и панель метрик голоса (вибрато, тон, спектр).
Все вычисления выполняются локально — аудио не отправляется на сервер.

Демо: https://zisam.github.io/voxmetrics-live/

Алгоритмы портированы из [voxmetrics](https://github.com/Zisam/voxmetrics): F0, вибрато, LTAS, H1-H2, форманты.
Метрики обновляются каждые 2 с по скользящему окну 6 с: частота/размах/регулярность вибрато, медиана F0 с нотой, форманты F1–F3, певческая форманта (пик 2.4–3.2 кГц и его выраженность), jitter, shimmer, CPP, H1−H2, спектральный центроид, S/F-баланс и LTAS-спектр.
Эталонные диапазоны показаны прямо в панели (легенда: норма / допустимо / вне нормы): вибрато 4.5–7.5 Гц с размахом 40–250 центов, регулярность ≥ 60 %, надёжность ≥ 4 с ровного тона, певческая форманта ≥ 6 дБ над фоном, jitter ≤ 0.15 %, shimmer ≤ 0.05 дБ (покадровые пороги, откалиброваны для этого измерения — не сравнивайте с экспортом Praat), CPP ≥ 10 дБ (ориентир); форманты и тон — ориентировочные/индивидуальные, зависят от гласного и типа голоса. Jitter/shimmer/CPP сильно зависят от микрофона и расстояния — главное их значение это тренд между подходами.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:5173/voxmetrics-live/ и разрешите доступ к микрофону.

## Сборка

## Ограничения live-режима

- Скользящее окно **5 с**: история движется влево, текущий сэмпл закреплён справа (ось X 0…5 с).
- Селектор канала в тулбаре: для стерео-интерфейсов (гитара слева, микрофон справа) — по умолчанию анализируется правый канал; моно-микрофон работает при любом положении.
- Нойз-гейт в тулбаре: порог RMS (дБFS) по умолчанию −50 дБ, регулируется ползунком (−90 дБ практически выключен). Гистерезис 4 дБ и сглаженные атака/релиз — без щелчков и дребезга.
- Узкополосный режектор 50 Гц убирает фон сети до анализа (не влияет на голос от 45 Гц и струны).
- Отклонение в центах (HUD) центрируется по медиане последних ~400 voiced-фреймов F0 (~2 с непрерывного звука при hop 5 ms).
- Realtime F0 и тяжёлый анализ метрик разделены по воркерам: анализ окна 6 с занимает <1 с и не тормозит график.
- «Надёжное» вибрато требует ≥4 с непрерывного озвученного звука в окне анализа.
- Для точного офлайн-анализа используйте Python [voxmetrics](https://github.com/Zisam/voxmetrics).
